# Manual Home Assistant Integration Instructions
# Follow these steps to add a Nuclei scan button to Home Assistant

1. First, upload the robust scan script to your NAS:
   - Copy the 'scan-with-ha-robust.sh' script to your NAS at /volume1/docker/nuclei/scripts/
   - Make it executable: chmod +x /volume1/docker/nuclei/scripts/scan-with-ha-robust.sh

2. Add this to your Home Assistant configuration.yaml file:

```yaml
# Nuclei Security Scanner Integration

# Shell command to trigger scan
shell_command:
  run_nuclei_scan: "docker exec nuclei-scanner /home/nuclei/scripts/scan-with-ha-robust.sh"

# Button for the Lovelace UI
button:
  - platform: template
    buttons:
      run_security_scan:
        friendly_name: "Run Network Security Scan"
        icon_template: "mdi:shield-search"
        press:
          service: script.run_security_scan

# Script that triggers the scan and provides feedback
script:
  run_security_scan:
    alias: "Run Security Scan"
    icon: mdi:shield-search
    sequence:
      # Update the status entity to show scanning
      - service: homeassistant.update_entity
        target:
          entity_id: sensor.nuclei_scanner_status
        data:
          state: "scanning"
      
      # Run the actual scan
      - service: shell_command.run_nuclei_scan
      
      # Show notification that scan was triggered
      - service: persistent_notification.create
        data:
          title: "Security Scan Triggered"
          message: "The network security scan has been started. You will be notified when it completes."
          notification_id: "security_scan_started"
```

3. Restart Home Assistant after adding this configuration

4. Add the button to your Lovelace dashboard:
   - Go to your dashboard
   - Click "Edit Dashboard"
   - Add a new card
   - Choose "Button" card
   - Select the "run_security_scan" entity
   - Save the card

5. You should now have a working button that triggers security scans

6. You can also add this automation to notify when scans complete:

```yaml
# Automation to notify when scan completes
automation:
  - alias: "Security Scan Completion Notification"
    trigger:
      platform: state
      entity_id: sensor.nuclei_scanner_status
      from: "scanning"
    action:
      - service: persistent_notification.create
        data:
          title: "Security Scan Complete"
          message: >
            The network security scan has completed.
            {% if states('sensor.nuclei_scanner_findings')|int > 0 %}
            🚨 {{ states('sensor.nuclei_scanner_findings') }} vulnerabilities were found!
            {% else %}
            ✅ No vulnerabilities were found.
            {% endif %}
          notification_id: "security_scan_complete"
```

7. For the Lovelace UI, you can also add this card to show scan status:

```yaml
type: entities
entities:
  - entity: sensor.nuclei_scanner
  - entity: sensor.nuclei_scanner_status
  - entity: sensor.nuclei_scanner_findings
  - entity: sensor.nuclei_scanner_hosts
  - entity: sensor.nuclei_scanner_last_scan
  - entity: sensor.nuclei_scanner_summary
  - entity: button.run_security_scan
title: Network Security Scanner
```
